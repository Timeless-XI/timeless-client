# Timeless XI client

The Timeless XI build of [vana-client](https://github.com/lenonk/vana-client) (MIT). Branch `timeless` carries our
changes on top of upstream `master`; every change is marked with a `Timeless XI:` comment so it is easy to find when
merging upstream.

## What is different from upstream

| Change | Where |
|---|---|
| A third interface, **Timeless** (Config > Settings > Client > Interface: Classic / Modern / Timeless). It is the modern layer drawn in the Timeless look; config `timeless_ui` (with `modern_ui` on). | `config.rs`, `client/settings.rs`, `client/mod.rs` (set each frame) |
| The Timeless palette, over the modern one: `assets/timeless/theme.json` (same keys as `assets/modern/theme.json`). A `timeless-theme.json` beside the client's `config.json` (`%APPDATA%\vana-client\`) replaces it at start-up, for trying colours without a rebuild. | `client/modern/theme.rs` |
| **Timeless hotbars** (Interface = Timeless): three bars of twelve slots on 1..0 - =, Ctrl + them and Alt + them. A slot holds a spell, ability, weapon skill, item, command line or **Attack** (engages the target, or disengages while engaged; the pack's attack / disengage icon on a red plate, lit while fighting; each job's first bar starts with it in slot 1), run through the same code as the game's menus and text commands. Left-click or the key runs it; right-click opens the picker (Magic / Abilities / Weapon Skills / Items / Commands, the last listing the chat line's recent commands); drag swaps slots, and dropping off the bars clears one. The number row opens the chat line only while the hotbars are off; Ctrl / Alt no longer raise or run the game's macro palette. A recast shows the Timeless logo's hourglass inside the icon, starting the slot's size and shrinking to nothing as its sand drains (seconds left in the corner), a press darkens the slot, and a ready slot flashes. Each bar is either kept per main job (default, FFXIV-style) or shared by every job: the bar's label shows ALL or the job (WAR ...) and a click switches, keeping what it showed. Saved per character as `timeless-hotbar-<name>.json` beside config.json (version 2: `shared_on`, the shared `bars`, `jobs` by job id). Config `timeless_hotbar` (Settings > Controls > Timeless Hotbars, default on) turns them off; the keys then open the chat line and run macros as before. | `client/timeless/` (logic, keys), `client/modern/tlbar.rs` (drawing); hooks in `client/mod.rs` (key arm after the chat line's, key functions), `client/modern/mod.rs`, `client/lua/{mod,actions}.rs` (actions reachable), `client/linehist.rs` (`recent`) |
| **Actions window** (the Actions button over the hotbars; Escape closes): Ability Book (Job Abilities by job with the level each comes at; Weapon Skills by weapon type with the skill level), Spell Book (White / Black / Summoning / Ninjutsu / Songs / Blue; the tooltip lists every job and level), Item Book (usable items drag straight from the Items list, which drags while the hotbars are on), Misc Book (Attack, Ranged, Check, Assist, Wide Scan, Map, Region Info, menus ...) and Commands. Tiles drag onto a slot. The tables are this server's: `assets/timeless/{abilities,weaponskills,spells}.tsv` from `tools/timeless/book_data.py <Phoenix dir> <out dir>` (base SQL + the era module's UPDATEs and weapon_skills.yaml, enabled expansions only, 75 cap). | `client/timeless/book.rs`, `client/modern/tlbook.rs`; `client/modern/items.rs` (rows drag), `client/lua/actions.rs` (`MENUS` reachable) |
| **Hotbar lock** (padlock left of Actions): locked = no slot set, swapped, dragged or cleared, no picker, the bars pinned where they stand (`Show.at`); saved in the hotbar file (v3). **Escape order**: our picker / Actions window close only when newer than the game window with the keys (opened or clicked later; modern `focus_panel` made pub(super)). **Misc slots toggle**: a second press closes the menu window it opened (Escapes sent through `UiInput.events`, only while that window or the main menu has the keys); Wide Scan folds its window. **Default places**: Timeless chat window as wide as its tab row (`chat.rs` room_default); the bars right of it, bottoms level (`Panels.retail`, until moved; a pre-v3 file forgets the saved place once). | `client/timeless/hotbar.rs`, `client/modern/{tlbar,chat,tabs,theme,mod}.rs`, `client/mod.rs` (Escape injection) |
| **Timeless Fishing** (every interface; was the Ashita add-on timelessfishing 2.16): on a Timeless XI server the fish's s2c 0x115 carries the bar game's settings (magic 0x5855) and the client plays the bar game instead of the arrow game: the movement keys steer the catch zone (the fishing statuses already hold the character still), Escape gives up, items and chests show a box (Enter reels in, Escape lets go). The client says hello (c2s 0x110 mode 5 para 10) on every zone-in and before every cast, reports the end (mode 3: 1 Perfect, 0 caught, 300 lost, 200 gave up, para2 = the special), the 10-seconds-left warning (mode 5 para 5); the rod pose (mode 5 para 6/7/8) is not sent for now (the server shows it by rewriting our status to 52 / 53, which this client read as the end of fishing; 52 / 53 now count as fishing while a round is up, and the movement axes are zeroed during a round); the arrow game's own sub-states then send the release. Other servers: the arrow game as before. `/tfish practice [0-100] [mixed\|smooth\|sinker\|floater\|dart] [monster]` plays a practice round. Server side: timeless-server `modules/timeless_fishing`. | `client/timeless/fishing.rs` (protocol, round physics, tests), `client/modern/tlfish.rs` (drawing, Timeless palette); hooks in `client/fishing.rs` (`on_timeless`, `practice`, `update`, `locked`, hello in `command`), `client/net.rs` (0x115 → `NetEvent::TimelessFish`), `client/mod.rs` (World `tl_fish`, the draw call after the modern layer), `client/textcmd.rs` (`/tfish`), `client/modern/tlbar.rs` (`hourglass` shared) |
| **Maximized window stays maximized** (Windowed mode): every settings change (a HUD element resized, logging in to a character, a volume ...) re-applied the window's mode and size, which took a maximized window out of maximized and back to Resolution's size. | **Stay logged in** (login screen, right of Remember password; ticking it ticks Remember password, unticking Remember password unticks it): at start the client logs in by itself with the remembered password and goes straight to the character menu (Select / Create / Delete Character ...). Config `stay_logged_in`. | `client/mod.rs` (`login_window` focus n + 7, `LoginView.stay`, `auto_login_done`), `client/modern/lobby.rs`, `config.rs` |
| **Update on the character menu**: when a newer Timeless XI client is out (Stay logged in can skip the login screen and its Update button), Select Character reads **Update** and Create / Delete Character are greyed out and refused; Update opens the Update window with only the client row ticked (never the game files: a retail file update would undo the Timeless DAT patches). | **Timeless Angler** (every interface; was the Ashita add-on timelessangler 1.39): the fishing **HUD** (drag it anywhere; shows with a rod in hand, while fishing or in a school): zone and fishing pool, rod and bait, the fish they hook here with the real chance per cast (difficulty colour, icons), items / monsters / no-bite share, fishing skill (+ gear), moon and seconds per bite, the **Fishing Spot Fatigue Tracker** (75-cast meter, cast #, school chance, distance from the spot, pond zones, **End school**), the session (time, fish, catches/hr, gil, top catches), Fish / Open Almanac / **Minimize** (folds the HUD into a "Fishing" tab on the right edge: one of the edge windows in Modern / Timeless, `extras.rs angler_tab`, place key `tl_angler`; its own tab in Classic; a click opens it) / **Close** (every fishing window off: HUD, banner, Almanac and its question; the client's own notices then go to the chat; `/angler show` brings them back). The spot is a mirror of the server's: casts = our status turning 56, the server's lines and catch lines from the chat log (`ChatLog::tap`). | `client/timeless/angler.rs` (tables, maths, spot mirror, tests), `client/modern/tlangler.rs` (HUD, banner, guide); hooks in `client/mod.rs` (World `angler`, `tick` after `fishing::update`, the draw call, game keys off while a guide filter has focus, egui takes the pointer over the HUD in Classic too), `client/combat.rs` (`ChatLog::tap`), `client/fishing.rs` (`on_bite`, `send_para`), `client/textcmd.rs` (`/angler`) |
| **HD classic icons** (Interface = Timeless): every game icon the Timeless interface draws (status effects, items, spells, abilities, mounts, emotes: the picture read from the player's own DATs, the Timeless interface always using the large status set and the game's spell / ability pictures rather than the modern pack's) goes through an HD upscaler the first time it is drawn: a Scale2x edge pass (tolerant colour match, run to 8x and halved), a Catmull-Rom bicubic pass for painted gradients, a blend of the two by local edge strength, a light unsharp mask, then one area (box) resample from the 4x master straight to the icon's size on screen (pixels per point, in twentieths; egui makes no mipmaps, so the GPU never shrinks it much). Premultiplied throughout, so transparent edges never darken. At most 6 ms of upscaling a frame: a full bag shows plain icons for a frame or two, each turning HD next frame. Nothing is shipped. | `client/timeless/hdicon.rs` (pipeline, tests), `client/modern/mod.rs` (`game_icon` used by `sprite_icon`, `item_icon`, `status_icon`; `list_icon` skips the pack art in Timeless) |

## Build (Windows)

`build_timeless.bat` (repository root) finds Visual Studio's 64-bit compiler, runs
`cargo build --release` and leaves `target\release\vana-client.exe`, which `VanaLocal\Play Timeless Local.bat` uses.

## Merging upstream

```
git fetch upstream
git merge upstream/master
```
Conflicts, if any, are in the files above. Run `cargo test -p vana-client theme` after a merge.
